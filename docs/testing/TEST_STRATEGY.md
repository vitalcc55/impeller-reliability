# Test Strategy

TypeScript unit covers operation-specific contracts, path и revision gate; Python unit/integration covers exhaustive JSONL dispatch, revision echo и WAL verdict. Browser preview проверяет renderer loading/ready/unavailable/error/restart states. Playwright Electron E2E завершает worker внутри дерева конкретного Electron, наблюдает unavailable event и доказывает controlled restart без второго worker. Packaging smoke подтверждает onedir, fuses, production CSP, `win-unpacked`, portable, отсутствие TCP и cleanup конкретного process tree. Critical algorithms require approved golden fixtures и branch/invariant coverage. Python coverage gate M01 — 85%; фактическое подтверждение даёт текущий `pnpm check`, а не отдельный status-документ.

M02.1 Python tests дополнительно доказывают atomic create, кириллицу/пробелы, close/reopen, optimistic revision, evidence audit только по изменённым полям, канонические UUID v4 audit events, audit rollback, corruption/newer schema без записи, bounded manifest с deadline, schema/evidence contract, backup before migration, timeout cleanup нового manual backup, закрытие connection после WAL failure и реальный lock contention с освобождением после crash. Vitest доказывает TypeScript boundary, последовательный dispatch/backpressure/deadlines и drain перед shutdown/restart. Electron E2E проверяет dirty draft, reattach/local discard, Main-owned close state, crash после close acknowledgement, завершение принятого save перед закрытием и create → update → close → reopen; packaged smoke повторяет persistence-сценарий. Browser preview остаётся синтетическим и не считается проверкой persistence.

M02.2A добавляет migration v1→v2 с verified v1 backup, Customer/WheelModel/Specimen CRUD, canonical decimal/date/UUID, incomplete warnings, no-op/conflict, archive restrictions, tamper-resistant entity audit и close/reopen persistence. Create retry с тем же UUID v4 не создаёт дубликат; contract tests доказывают одинаковую нормализацию TypeScript/Python, integrity tests отклоняют no-op audit revision и активный образец под архивной моделью, WAL recovery test проверяет уже зафиксированную schema после аварийного завершения. Electron E2E проходит customer → wheel model → specimen → archive/restore → reopen и общий dirty lifecycle для навигации, архивного действия, restart и window close. Packaged smoke после reopen сверяет идентификаторы, связь образца с моделью, значения, диаметры и revisions через bundled worker.
