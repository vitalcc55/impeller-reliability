# R130SH Run Contract

Будущий входной пакет результата R130SH содержит manifest, сведения о фактически применённом режиме, run summary, provenance, events, full measurements, inspections, attachments, optional spectra/protocol и checksums. Обязательны независимые status/outcome/validity/completeness/observation classifiers и provenance стенда. Идемпотентный ключ: packageId + exportRevision + packageHash. Расширение и точный состав фиксируются только после получения реального обезличенного экспорта R130SH; Impeller Reliability не определяет исходящий контракт для стенда.

M02.1 не реализует importer.
