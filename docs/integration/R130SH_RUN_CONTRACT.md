# R130SH Run Contract

`.r130run` содержит manifest, original/effective/amendments plan, run summary, provenance, events, full measurements, inspections, attachments, optional spectra/protocol и checksums. Обязательны независимые status/outcome/validity/completeness/observation classifiers и provenance стенда. Идемпотентный ключ: packageId + exportRevision + packageHash.

M01 не реализует importer.
