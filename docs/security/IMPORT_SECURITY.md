# Import Security

M03A/M03B `.r130run` validation открывает выбранный ordinary file read-only, сравнивает initial/final stat и не извлекает ZIP. Strict safety profile ограничивает outer bytes, central directory, entry count/metadata/path, cumulative decompressed bytes, JSON size/depth/nodes, JSONL line, CSV physical record/field и returned findings. Absolute/traversal/backslash/control/BOM/duplicate/case-collision/symlink/special/encrypted/unsupported entries отклоняются. Raw stored/DEFLATE range полностью потребляется; фактические size/CRC/SHA-256 сверяются независимо от manifest/central declarations.

Absolute source path, payload bytes, stack trace и unsafe finding location не возвращаются Renderer и не логируются. M03B копирует пакет потоково в operation-owned `.staging/<local-import-id>.part`, независимо считает outer SHA, повторно валидирует staged copy и атомарно публикует exact managed path. До commit удаляется только operation-owned orphan; recovery удаляет только незарегистрированные файлы точной grammar и не является общим filesystem journal. После commit registry/hash не переписываются даже при missing/modified archive. `diagnostic_partial` требует явного подтверждения и не допускается к расчётам по умолчанию.

M02.2B managed CaseDocument attach is not `.r130run` import and does not share its staging/parser model. It accepts only `.pdf`, `.docx`, `.xlsx`, `.csv`, `.json`, `.txt`, `.png`, `.jpg`, `.jpeg` up to 100 MiB, repeats signature/UTF-8 checks in Python, streams into `assets/documents` staging and registers an immutable SHA-256 copy. Archive does not delete content; verify/open never trusts a Renderer path. Document contents are not parsed, indexed, logged, audited or committed to the public repository.
