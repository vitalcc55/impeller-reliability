# Import Security

M03A `.r130run` validation открывает выбранный ordinary file один раз read-only, сравнивает initial/final stat и не извлекает ZIP, не создаёт staging/assets и не меняет Project. Strict safety profile ограничивает outer bytes, central directory, entry count/metadata/path, cumulative decompressed bytes, JSON size/depth/nodes, JSONL line, CSV physical record/field и returned findings. Absolute/traversal/backslash/control/BOM/duplicate/case-collision/symlink/special/encrypted/unsupported entries отклоняются. Raw stored/DEFLATE range полностью потребляется; фактические size/CRC/SHA-256 сверяются независимо от manifest/central declarations. Высокий compression ratio сам по себе не является запретом.

Absolute source path, payload bytes, stack trace и unsafe unsanitized finding location не возвращаются Renderer и не логируются. Report намеренно содержит bounded basename выбранного файла, package-relative безопасные locations и ограниченную contract metadata; содержимое пользовательских payload не возвращается. Cancellation/deadline проверяются между chunks/entries/records; source growth немедленно даёт `source_changed`. Защита от malware и намеренной same-user подмены с восстановлением всех stat-атрибутов вне модели. M03B позднее добавит отдельные staging/retention/import controls после M9a; M03A report не подтверждает production compatibility и не допускает `diagnostic_partial` к расчётам.

M02.2B managed CaseDocument attach is not `.r130run` import and does not share its staging/parser model. It accepts only `.pdf`, `.docx`, `.xlsx`, `.csv`, `.json`, `.txt`, `.png`, `.jpg`, `.jpeg` up to 100 MiB, repeats signature/UTF-8 checks in Python, streams into `assets/documents` staging and registers an immutable SHA-256 copy. Archive does not delete content; verify/open never trusts a Renderer path. Document contents are not parsed, indexed, logged, audited or committed to the public repository.
