# Electron Security

Required window flags: `nodeIntegration=false`, `contextIsolation=true`, `sandbox=true`, `webSecurity=true`, `allowRunningInsecureContent=false`. External navigation, `window.open` и permissions запрещены. Preload exposes only typed system/project/dossier/caseDocument methods/events; generic channel и передача произвольного project/document path запрещены. CaseDocument file dialog и `shell.openPath` принадлежат Main, registry containment/hash — Python; Renderer видит только metadata/status и typed outcome. Запрос закрытия окна является отдельным Main → Renderer event: dirty draft требует явного решения, а Renderer может подтвердить только закрытие приложения, не произвольную системную операцию.

Первичные материалы R130SH открываются через `importedRun.openMaterial`: Renderer передаёт только точную identity и UUID операции. Main добавляет разрешённый каталог/имя и бюджет копии во внутренний worker request. Python выбирает единственный зарегистрированный JPEG/PNG либо фиксированный PDF этой редакции, проверяет metadata, inventory, bytes/size/SHA и сигнатуру типа на том же ZIP handle; лимит копии — 100 MiB. Windows handles закрепляют обычные каталоги и новый файл, запрещая запись/замену до завершающей проверки SHA архива. Копия создаётся эксклюзивно под именем операции и не возвращается до окончания проверок. При отказе удаление назначается именно открытому файловому объекту через `FileDispositionInfo` до освобождения handle, без повторного удаления имени по пути. Бинарные данные и локальный путь не входят в публичный ответ.

Main единолично владеет отдельным каталогом копий вне `.irproj`, проверяет containment, ordinary file, отсутствие links, размер, выделенный резерв и SHA перед системным вызовом, включая повторную проверку после публикации handoff-маркера. Номер сессии меняется при начале смены/закрытия проекта, перезапуске/потере worker и завершении приложения; устаревший или отменённый запрос не передаётся ОС. Успех означает только пустой error result `shell.openPath`. Строка ошибки и rejected Promise дают `material_open_failed`; test-only shortcut для этой операции отсутствует.

Копии ограничены общей ёмкостью 400 MiB и 64 операциями. Служебные каталоги состояния относятся только к cleanup и не являются registry первичных материалов. Уникальный пустой claim-каталог публикуется до проверки других владельцев; живой сосед даёт `operation_in_progress` без ожидания и повторов. Имя отдельного каталога копии содержит PID Main/worker, UUID и резерв; файловая identity и handoff фиксируются атомарным созданием пустых дочерних каталогов. Частично записанного JSON-маркера нет. Каталог должен быть локальным; UNC запрещён. Повторное использование PID может консервативно задержать очистку.

Main удаляет только пустые каталоги через `rmdir`. Байты удаляет внутренняя `materialCopy.discard`: worker закрепляет каталог, открывает фиксированный UUID JPEG/PNG/PDF, сверяет точные volume/file ID (16/32 lowercase hex), обычность и отсутствие links, затем назначает удаление этому же handle. Операция не зависит от открытой сессии дела и недоступна через Preload. До остановки worker Main отменяет и дожидается операций открытия. Отмена или определённый отказ открытия фиксируют terminal cleanup intent до удаления: при последующем сбое worker копия с известной identity может очищаться при следующей подготовке, включая случай незавершённого удаления handoff-маркера. При недоступном worker, чужом файле или неизвестной identity копия сохраняется и учитывается в лимите; открытие такой копии не объявляется проверенным. Переданные ОС и неопределённые попытки сохраняются: Electron не сообщает о закрытии viewer. Заполненная ёмкость даёт явный отказ без вытеснения.

Development HTML разрешает Vite WebSocket только на `127.0.0.1:5173`. Packaged renderer обслуживается только из `app.asar` через ограниченный `impeller://app/` handler; path traversal и другой host отклоняются. Production build проверяет отдельную CSP с `connect-src 'none'` и без network origin, а renderer не получает расширенных привилегий `file://`.

После упаковки `@electron/fuses` явно отключает `RunAsNode`, `NODE_OPTIONS`, CLI inspect, browser-specific snapshot и extra file privileges; включает cookie encryption, embedded ASAR integrity, `OnlyLoadAppFromAsar` и WASM trap handlers. Конфигурация требует явного значения каждого fuse и перечитывается из packaged executable. Worker SHA-256/self-test проверяются отдельно. Подпись EXE остаётся явно отложенным production-решением.
