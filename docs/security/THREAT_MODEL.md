# Threat Model

Assets: project DB, immutable imports, reports, source documents and calculation provenance. Trust boundaries: untrusted renderer content, user-selected files, Main↔worker JSONL, external R130SH packages. Primary threats: renderer privilege escalation, generic IPC, worker substitution, ZIP traversal/bombs, contract confusion, CSV injection, stale response, data tampering and orphan processes. Controls are split across Electron hardening, integrity-checked worker, schema/checksum validation and immutable snapshots.

M02.1 controls project-path confusion by allowing create/open selection only in Main; recent paths are Main-owned allowlisted entries, но выбранный контейнер всё равно недоверенный. Python отклоняет отсутствующие, связанные и структурно неверные reserved paths, читает manifest не более 4 KiB и выполняет immutable read-only SQLite validation (`application_id`, schema, migration ledger, projectId и metadata/audit evidence). Только после этого worker захватывает OS lock и открывает SQLite на запись. Invalid/newer/schema-tampered SQLite не получает WAL/backup, а atomic staging предотвращает частичный новый проект.

Timestamp-поля недоверенного manifest/SQLite не считаются безопасными строками: Python проверяет точный UTC-формат с миллисекундами, реальную календарную дату, порядок metadata/audit и совпадение project-created evidence до открытия сессии. TypeScript повторяет формат на IPC boundary, поэтому crafted дата не достигает renderer formatting как runtime exception.

Main↔worker transport зеркалит последовательную обработку JSONL: одновременно отправляется одна операция, ещё одна может ожидать, дальнейшие отклоняются backpressure; deadline начинается при dispatch, а не при ожидании в Main. Graceful shutdown и controlled restart закрывают приём новых запросов, дренируют принятую bounded-очередь и затем отправляют `system.shutdown`; final shutdown отменяет пересекающийся restart, поэтому lifecycle не обходит Python cleanup и не создаёт replacement/orphan worker. `SIGKILL` остаётся аварийной реакцией на protocol violation или indeterminate transport timeout, а не обычным shutdown path.

Активная злонамеренная подмена файлов другим процессом того же Windows-пользователя во время уже начатой операции не входит в модель угроз локального однопользовательского продукта. Приложение не содержит повторных identity-проверок, custom SQLite VFS или ACL-подсистемы для такого сценария.
