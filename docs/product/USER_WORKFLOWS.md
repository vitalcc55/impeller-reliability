# User Workflows

Целевой поток: независимо выполнить испытание в R130SH → получить машинный пакет результата → создать/открыть `.irproj` → импортировать неизменяемые стендовые факты → дополнить заказчика, модель, образец и нормативные источники → выполнить расчёты и классификацию → создать immutable analysis/report snapshot → выпустить документ.

Impeller Reliability не готовит и не передаёт план в R130SH. Расчёты РБД/РПТ/ПМН являются внутренней последующей аналитикой проекта, а не контуром управления стендом.

M01 поддерживает только запуск приложения, показ runtime health, ручной ping и открытие технического журнала.
