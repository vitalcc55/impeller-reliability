# User Workflows

Целевой поток: создать/открыть `.irproj` → описать модель и образцы → подготовить версионированный план → экспортировать `.r130plan` → выполнить испытание в R130SH → импортировать `.r130run` → проверить план/факт и классификацию → создать immutable analysis/report snapshot → выпустить документ.

M01 поддерживает только запуск приложения, показ runtime health, ручной ping и открытие технического журнала.
