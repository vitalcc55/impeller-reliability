# Product Scope

Impeller Reliability — локальная однопользовательская офлайн-система для аналитических дел надёжности рабочих колёс: импорт неизменяемых результатов R130SH, дополнение сведений, последующий анализ и зафиксированные выпуски документов.

Внутри продукта: аналитические дела, образцы, downstream-группировки импортированных запусков, РБД/РПТ/ПМН, FMEA/FMECA, статистика/Вейбулл, Марков, Монте-Карло, вибрация, справочники и экспорт. Вне продукта: исполняемые планы R130SH, управление стендом, Modbus, interlocks, аварийный останов, аттестация стенда, сервер/облако.
