# Product Scope

Impeller Reliability — локальная однопользовательская офлайн-система для проектов надёжности рабочих колёс: планы испытаний, импорт неизменяемых результатов R130SH, аналитика и зафиксированные выпуски документов.

Внутри продукта: проекты/образцы/кампании, РБД/РПТ/ПМН, FMEA/FMECA, статистика/Вейбулл, Марков, Монте-Карло, вибрация, справочники и экспорт. Вне продукта: управление стендом, Modbus, interlocks, аварийный останов, аттестация стенда, сервер/облако. M00–M01 реализует только инфраструктуру.
