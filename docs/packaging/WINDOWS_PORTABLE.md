# Windows Portable

Внешний артефакт: `ImpellerReliabilityCalc-<version>-portable-x64.exe`. Electron содержит `app.asar`; `resources/python-worker` — PyInstaller onedir с manifest/SHA-256; Main проверяет digest перед запуском. `afterPack` применяет и перечитывает production fuses, повторяет integrity check и worker self-test. `scripts/smoke/desktop.ps1` получает version из package metadata и проверяет handshake/ping/SQLite/shutdown, fuses, TCP и orphan worker только в дереве конкретного запуска.

M01.1 measurement on Windows 11: worker onedir 93,232,197 bytes; `win-unpacked` 493,327,714 bytes; portable 121,359,401 bytes (ниже research target 200 MB), SHA-256 `8e676a94a1e85c2f04862e5871f17ad44354b29a592ed8d45bd30bf6b2556134`. Полная готовность от launcher в финальном gate: `win-unpacked` 8.943 s, portable с распаковкой 28.777 s. Цель `<5 s` в этом cold run не выполнена; это остаётся измеренной целью исследования, а не скрытым обещанием. Внутренний post-window smoke занимает 8 ms и не подменяет full startup measurement.
