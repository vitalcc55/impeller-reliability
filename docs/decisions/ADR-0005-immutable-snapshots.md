# ADR-0005 — неизменяемые imports, analysis snapshots и report releases

- Статус: принято
- Дата: 2026-08-25

## Контекст

Инженерный результат должен воспроизводиться после изменения проекта, алгоритма, справочника или шаблона отчёта. Исходные факты R130SH нельзя редактировать.

## Решение

Импортированный пакет и hash сохраняются неизменно. Каждая аналитическая интерпретация получает input snapshot/hash и версии алгоритмов/справочников; выпущенный документ ссылается на immutable ReportSnapshot.

## Альтернативы

Пересчёт из текущего mutable state упрощал бы хранение, но разрушал воспроизводимость. Редактирование импортов смешивало бы факт и интерпретацию.

## Последствия

Изменение создаёт новую ревизию или snapshot; старые выпуски остаются воспроизводимыми. Потребуются явные retention и archive policies.

## Риски

Рост объёма и путаница ревизий. UI обязан показывать происхождение, активную интерпретацию и различия, не удаляя прежние факты.
