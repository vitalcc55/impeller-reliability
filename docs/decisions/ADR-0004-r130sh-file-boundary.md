# ADR-0004 — файловая граница R130SH и отсутствие управления стендом

- Статус: принято
- Дата: 2026-08-25

## Контекст

R130SH владеет исполнением стендового запуска и первичными фактами. Аналитическое приложение не должно зависеть от внутренних классов, SQLite или Modbus-карты стенда.

## Решение

Граница односторонняя: R130SH независимо проводит испытание и выпускает версионированный машинный пакет результата с manifest, checksums и происхождением; Impeller Reliability только импортирует этот пакет. Impeller Reliability не формирует задания для R130SH, не отправляет команды управления оборудованием и не читает SQLite R130SH.

## Альтернативы

Общая БД и прямой API связывали бы жизненные циклы приложений. Исходящий файл плана не требуется утверждённым пользовательским процессом. Восстановление фактов из PDF теряло бы машинную полноту и provenance.

## Последствия

Приложения выпускаются независимо; schema входного результата и cross-repository fixtures становятся утверждённой интеграционной границей.

## Риски

Повреждённые, чрезмерные или несовместимые пакеты. До M04 требуются JSON Schema, canonical hashing, безопасный ZIP import и positive/negative fixtures.
