# ADR-0006 — офлайн NSIS Setup для текущего пользователя

- Статус: принято
- Дата: 2026-10-23

## Контекст

Заказчик получает один файл по LAN и работает офлайн. Ежедневный запуск не должен распаковывать весь программный комплект. Обновление должно сохранять дела и профиль, а несохранённая работа не допускает принудительного закрытия приложения.

## Решение

Полный NSIS x64 Setup устанавливает программу строго для текущего пользователя. Сохраняются Electron identity и PyInstaller onedir. Один Setup поддерживает initial install, upgrade и равную переустановку; downgrade блокируется до удаления старой версии. Штатные NSIS hooks заменяют force-kill ожиданием ручного закрытия с Retry/Cancel, включая worker и встроенный uninstaller. Удаление сохраняет профиль и внешние дела; Main запрещает рабочие дела внутри заменяемого дерева программы.

## Альтернативы

Online updater, служба обновления и автоматический rollback не нужны для ручной офлайн-передачи. Вложенный onefile создаёт двойную распаковку и не применяется. Смена Electron/Python не требуется.

## Последствия

Одна поддерживаемая внешняя поставка. WinUnpacked остаётся диагностическим payload. Сохранность доказывается чтением дела версии N установленной версией N+1. Политика и сопровождение — в [Windows Setup](../packaging/WINDOWS_SETUP.md); gates принадлежат [tests/AGENTS.md](../../tests/AGENTS.md).

Штатный ZIP-extractor и ненулевой код до полного успеха исключают подтверждённый fallback 7z, игнорирующий ошибки записи. Минимальный pnpm patch locked `app-builder-lib@26.15.3` удаляет безусловную запись Setup в updater-кэш и добавляет `/SD IDOK` к ошибке ZIP для завершения silent-запуска без ожидания диалога; runtime copy/delete не добавляется. При обновлении зависимости части патча пересматриваются отдельно: отключение кэша снимается при штатной настройке либо отдельном внедрении updater, исправление ZIP — при штатной обработке silent-ошибки. Версии зависимостей сохраняются.

## Риски

Неподписанный Setup может быть запрещён политикой рабочего места; необходим пробный запуск. Невозможность наблюдать процессы блокирует замену. Сбой установки требует повторного полного Setup; атомарность при произвольном отключении питания не гарантируется. Будущее изменение опубликованного формата потребует согласия и проверенного backup, без искусственной schema сейчас.
