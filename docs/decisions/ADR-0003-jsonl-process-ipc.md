# ADR-0003 — UTF-8 JSONL process IPC

- Статус: принято
- Дата: 2026-08-25

## Контекст

Electron Main должен безопасно вызывать локальный Python worker без сетевого backend, открытого порта и локальной авторизации.

## Решение

Использовать одну JSON-строку на сообщение через stdin/stdout. Каждая известная операция имеет конкретные request/result-схемы, requestId, revision и deadline; stdout зарезервирован протоколу.

## Альтернативы

HTTP/TCP добавлял бы listener и сетевую поверхность. gRPC требовал бы тяжёлый toolchain. Одноразовый subprocess на операцию ухудшал бы startup и lifecycle.

## Последствия

Протокол прост для fixtures и логической трассировки, но крупные данные должны передаваться файлами. Несовместимое изменение требует новой версии протокола.

## Риски

Большие/невалидные сообщения, stale responses и зависший процесс. Ограничения размера, operation allowlist, revision gate, timeout и bounded shutdown являются обязательными.
