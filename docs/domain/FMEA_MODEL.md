# FMEA/FMECA Model

Исследование содержит methodology snapshot, items, risk policy, corrective actions, residual risk и report snapshot. `RPN=S×O×D`, но шкалы, подписи, цвета, пороги и правила принятия задаются версией утверждённой методики. Значения 50/100 и заменённый ГОСТ не кодируются как вечная норма.
