# Первичные материалы запуска

Контрольные архивы созданы production exporter R130SH из изолированной копии
коммита, указанного в [UPSTREAM_SOURCE.json](UPSTREAM_SOURCE.json). Все факты
синтетические: фотографии и PDF служат проверке программного обмена и не являются
материалами реального лабораторного испытания. Рабочий R130SH и оборудование не
использовались. CI читает сохранённые архивы без установки или checkout производителя.

Один сохранённый запуск экспортирован до выпуска PDF, после первого сохранённого
выпуска и после второго выпуска изменённого черновика. Поэтому редакции экспорта
1/2/3 отличаются от редакций протокола 1/2. Package ID и зарегистрированные
фотографии этого запуска сохраняются. Отдельный diagnostic partial содержит
зарегистрированную недоступную фотографию с причиной и без подставленных bytes.
Оба синтетических запуска имеют собственные source Specimen IDs, не совпадающие
с образцами frozen M9a; чтение в общем smoke-деле поэтому проверяется до привязки.

Для воспроизведения применяется существующий seed из
`tests/helpers/m9a_run_packages.py`: создание bundle, сохранение измерения,
завершение и лабораторное заключение. Только в изолированном helper задаются
версия, синтетический build label и точный producer commit вместо M9a placeholders.
`LaboratoryProtocolWorkspace.add_photo` сохраняет JPEG осмотра и PNG всего запуска,
созданные Qt `QImage`/`QPainter` с надписью `SYNTHETIC SOFTWARE TEST`.
Сохранение черновика, `prepare_release_request`/`prepare_render_context` и
`LaboratoryProtocolExportService.release` создают обе PDF-редакции штатным renderer;
они проверены `QPdfDocument`. Каждый архив выпускает `RunPackageExportService`.
В отдельном изолированном запуске удалён только его управляемый файл фотографии,
после чего production exporter выпускает diagnostic partial с явной причиной.

Источник правил consumer, происхождение frozen M9a и producer этих новых архивов
имеют разные роли. Их идентичности и package/member hashes находятся только в
каноническом provenance manifest. Замороженные M9a и PMN reference не изменены.
