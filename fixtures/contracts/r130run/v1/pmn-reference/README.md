# Пакет ПМН от актуального exporter R130SH

`pmn_reference_export.r130run` создан через production `RunPackageExportService` из изолированного архива исходников R130SH. Точный commit, SHA-256 пакета, идентификаторы и версия находятся в [`UPSTREAM_SOURCE.json`](UPSTREAM_SOURCE.json). Исходные факты синтетические: без запуска стенда, физических измерений или изменения рабочего дерева R130SH.

В изолированной копии использован PMN seed из `tests/helpers/m9a_run_packages.py`: 1500 об/мин, коэффициент 1,1, два цикла и фазы 2/1/2 с. Для корректной provenance в копии seed изменены только версия, метка синтетической сборки и Git commit; код exporter не менялся. SQLite seed и экспортный receipt создавались в ignored `.tmp` текущего workspace, вне версионируемых файлов и рабочего дерева R130SH. Receipt подтвердил публикацию и совпадение SHA-256 с версионируемым архивом.

Интеграционный тест проверяет целостность архива, provenance, оба плана, импорт, точный расчёт и повторное открытие дела. Пакет лежит отдельно от неизменяемых 21 M9a архивов. Это доказательство программного обмена, а не приёмка физического испытания.
